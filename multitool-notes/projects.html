Lab 1 • Full-Stack

Multi-Tier Blogging Platform

A secure full-stack web application employing ExpressJS routing middleware and modular EJS view engine parsing. Implements dynamic JSON data seeding, relational Mongo query CRUD integrations, and custom route checks.

EJS View Engine partials
Express CRUD middleware
Mongoose Schema validation
Robust query sanitization
Prerequisites & Init commands
# Initialize node directory
npm init -y
# Install core express, ejs and mongoose
npm install express ejs mongoose
# Install nodemon development server
npm install --save-dev nodemon
Run Local Environment
# Check if local Mongo shell active
mongosh --eval "db.runCommand({ ping: 1 })"

# Start Express server with file watching
npm run dev

Lab 2 • Cloud Native

Kubernetes Microservices Mesh

Containerizing our database and deploying a secure, highly available database engine on a local Kubernetes cluster. Implements decoupled Storage systems (PVC), ConfigMaps, cluster secret injection, and Ingress routing rules.

Minikube Cluster state
Persistent Volume storage
Base64 encoded Secret maps
Ingress Hostpath controllers
Start Cluster & Apply Manifests
# Start local Minikube cluster
minikube start --addons=ingress

# Apply cluster configuration rules
kubectl apply -f mongo-secret.yaml
kubectl apply -f mongo-configmap.yaml

# Provision Database container
kubectl apply -f mongo-pvc.yaml
kubectl apply -f mongo.yaml
Debugging & Troubleshooting
# Get all deployed pods and services
kubectl get all

# View streaming database server logs
kubectl logs -f deployment/mongodb-deployment

# Fetch ingress routing host path IP
kubectl get ingress

Lab 3 • Automation

CI/CD Automation Pipeline

Configuring a continuous delivery flow utilizing GitHub Actions triggers. Automates code checkouts, installs npm packages caching node_modules, validates JavaScript ES6 coding standard linters, runs unit tests, and packages docker builds.

GitHub Actions triggers
Node_modules caching caching
Jest automated unit tests
Automatic Docker Hub upload
Actions workflow manifest (.yml)
# Save inside .github/workflows/deploy.yml
name: Build and Deploy Test Pipeline
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm test
Local Docker Packaging
# Create container image file
docker build -t my-app:latest .

# Run and map ports locally
docker run -p 3000:3000 --env-file=.env my-app:latest
